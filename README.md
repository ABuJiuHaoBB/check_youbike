# YouBike 2.0 決策助手（check_youbike）

一個給 **YouBike 2.0 臺北市公共自行車** 的**決策支援網頁**。
不是「展示數據」，而是幫你回答：「我該去哪借車、我該去哪還車。」

> 純前端、無後端、無框架；單一 HTML 檔，部署於 GitHub Pages。
> 網址：`https://abujiuhaobb.github.io/check_youbike/`

---

## 為什麼做這個

- **下班找車**：官方 App 用顏色粗表示滿/空，要看細節得點擊站點，無法一眼判斷「哪一站最可能借到車」。
- **到目的地還車**：到了才發現沒空位，要滑地圖找鄰站，常常被迫繞路或等待。
- **只看「可借/空位」原始數量會誤判**：不同站的總車格數不同，原始數字無法跨站比較。

## 功能

- **借車 / 還車** 兩種模式（分段控制器切換）。
- **大卡 = 推薦站**；下方 **2×3 共 6 個鄰近站**（依距離）。
- 每張卡顯示：站名、**可借／空位數**、總格（還車小字參考）、**距離＋方向**、**步行／騎車時間**、更新時間。
- **狀態色**：綠（機會高）、黃（有機會）、紅（先不要）。
- 更新時間超過 2 分鐘未更新 → **紅色警示「超過兩分鐘未更新」**。
- **整張卡片可點擊** → 開啟 Maps 顯示該站。
- **每 60 秒自動刷新**（資料來源為官方即時 JSON，CORS 開放，瀏覽器可直接抓取）。

### 借車顏色門檻（車數）
>10 機會高（綠）／3–9 有機會（黃）／0–2 先不要（紅）

## 使用方式

1. 開啟網址（建議用手機 Safari）。
2. 首次允許「定位服務」。
3. 切換「借車／還車」模式；頁面每 60 秒自動刷新官方資料。

## 技術與部署

- **單一 `index.html`**（HTML + CSS + JavaScript 全內嵌），無框架、無後端、無外部依賴。
- neighborhood_index.json：靜態空間索引
- 邊緣運算 + 靜態空間索引（手機端本地建索引，免上傳重算）
- 站點指紋（FNV-1a）自動偵測站點集合變動
- 邊緣站標記（400m 無鄰站 16 站，階層孤兒 3 ⊆ 備選不足 6 ⊆ 邊緣 16）
